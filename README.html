Como publicar no GitHub Pages

O pacote é 100% estático e pode ser hospedado diretamente a partir de um repositório GitHub.

  1. Crie um repositório no GitHub.
  2. Envie todos os arquivos e pastas deste pacote para a raiz.
  3. Acesse Settings → Pages.
  4. Selecione Deploy from a branch, branch main e pasta /(root).
  5. Salve e aguarde a URL publicada.

Nenhum backend, banco de dados ou processo de build é necessário para os simuladores locais.

Dados do aluno

Progresso, anotações e resultados são armazenados no localStorage do navegador. Use a página Meus dados para exportar um backup antes de trocar de computador, navegador ou domínio.
