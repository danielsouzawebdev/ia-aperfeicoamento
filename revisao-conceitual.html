🧭 Revisão conceitual

Dez distinções que você precisa dominar para projetar soluções empresariais de IA e automação sem confundir ferramenta com arquitetura.

10 distinções essenciais

Tarefa × ProcessoTarefa é uma ação; processo é a cadeia que produz um resultado de negócio.
Processo × WorkflowProcesso descreve o trabalho; workflow operacionaliza etapas, decisões e sistemas.
IA × RegraIA interpreta ambiguidade; regra determinística aplica critérios previsíveis.
Prompt × ContratoEm produção, o prompt precisa definir entradas, regras, limites e saída consumível.
JSON válido × Dado válidoSintaxe correta não garante significado correto.
IF × SwitchIF bifurca; Switch organiza múltiplas rotas.
Retry × Repetição infinitaRetry profissional possui limite, espera e critério para desistir/escalar.
Structured output × Tool callingUma organiza resposta; a outra permite solicitar uma ação externa.
Workflow × AgenteWorkflow segue lógica prevista; agente escolhe caminhos/ferramentas dentro de limites.
Funcionar × Estar pronto para produçãoProdução exige segurança, observabilidade, custos, tratamento de erro, responsável e rollback.

⚠️ 8 anti-padrões para reconhecer

  1. Automatizar processo que ninguém entende.
  2. Usar IA para regra simples e determinística.
  3. Confiar em JSON sem validar valores.
  4. Guardar API key em prompt, código ou planilha.
  5. Não prever fallback ou revisão humana.
  6. Repetir API indefinidamente após erro.
  7. Dar ao agente mais ferramentas do que precisa.
  8. Publicar sem métrica, log e responsável.
