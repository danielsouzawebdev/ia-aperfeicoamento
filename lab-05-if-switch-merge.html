Lab 05 • n8n intermediário

IF × Switch + Merge

Escolha a estrutura de decisão adequada e entenda como branches podem voltar a convergir.

🎯 Objetivos

  • Distinguir IF e Switch.
  • Entender por que múltiplas branches precisam de fallback.
  • Usar Merge quando dados/caminhos precisam voltar a convergir.

1. IF ou Switch?

Comercial
Nutrição
Automação leve
Revisão humana

💡 Analogia

IF é uma catraca: passa ou não passa. Switch é uma central de triagem: cada categoria segue para um destino diferente.

2. Merge — quando os caminhos voltam

Branch A
[{id:1,nome:'Ana'}, {id:2,nome:'Bruno'}]
⇢
Branch B
[{id:1,score:82}, {id:2,score:51}]


🧠 Pare e pense
Se o Gemini retorna cinco categorias possíveis, usar vários IFs encadeados funciona, mas tende a ficar mais difícil de ler. Um Switch torna a intenção do fluxo explícita e permite uma rota fallback.
