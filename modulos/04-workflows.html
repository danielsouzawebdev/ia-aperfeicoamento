1. O que cada componente faz?

Gatilho

Inicia o fluxo: formulário, horário, webhook, e-mail, novo registro.

Ação

Cria, consulta, transforma ou envia algo.

Condição

Cria caminhos diferentes conforme uma regra.

Entrada/Saída

Dados que entram e dados que cada etapa produz.

Exceção

Define o que fazer quando algo falha ou vem incompleto.

Humano no loop

Interrompe o fluxo quando há necessidade de revisão/aprovação.

⚠️ Fluxo feliz não basta

Um bom workflow também pergunta: e se o dado não vier? E se a API falhar? E se a IA responder com baixa confiança? E se a ação for irreversível?

💡 Analogia: workflow é uma linha de montagem de informação

Cada estação recebe algo, executa uma transformação ou decisão e entrega uma saída para a próxima. Se um nó espera email e o anterior entrega email_cliente, a “peça” não encaixa. Por isso, workflows confiáveis dependem de contratos entre etapas.

🔎 Caminho feliz, exceção e compensação

Caminho feliz

Entrada válida → processamento → resultado esperado.

Exceção

Campo ausente, API indisponível, resposta inesperada ou regra não satisfeita.

Compensação

O que fazer depois de uma falha parcial: registrar, reverter, notificar ou encaminhar.

Pare e pense: se o e-mail foi enviado, mas a atualização no CRM falhou, qual é o estado correto do processo? Um workflow profissional precisa responder a isso.
