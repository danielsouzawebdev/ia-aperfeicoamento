# IA para Empreendedores — Aperfeiçoamento v9

Curso autoinstrucional estático de **12h (720 min)**, focado em Gemini + n8n, Engenharia de Prompts, processos, workflows, APIs, automação, agentes e preparação para produção.

## Recursos principais
- 10 módulos oficiais / 720 minutos.
- 60 questões no banco avaliativo; 12 sorteadas por tentativa.
- Mini-projeto n8n com Webhook → mapeamento → Gemini + IF → Sheets/Gmail + aprovação humana.
- Laboratórios de JSON, APIs, troubleshooting, IF/Switch/Merge, Loop, Wait/Retry e Error Workflow.
- Sub-workflows, observabilidade, custos, credenciais, arquitetura e checklist de produção.
- Tool calling, memória/contexto, human-in-the-loop e avaliação de agentes.
- Projeto Integrador com exportação local.
- Painel final de desempenho, conclusão e certificado simbólico.
- Modo Instrutor ampliado.
- Backup/restauração dos dados do curso.

## Novidades da v9
- Painel de desempenho consolidado: módulos, avaliação, projeto e prontidão de produção.
- Página de conclusão com síntese das competências e pitch final.
- Trilha visual completa do problema à produção.
- Certificado simbólico condicionado a 10/10 módulos e pelo menos 70% na autoavaliação.
- Relatório final exportável em TXT.
- Modo Instrutor com roteiro das 12h, demonstrações, erros conceituais e rubrica de 100 pontos.

## Publicação
Abra `index.html` localmente ou publique todos os arquivos no GitHub Pages. O site é 100% estático e não exige Node.js, banco de dados ou backend para os simuladores locais.


## Revisão pedagógica — versão 9

A v9 preserva os 10 módulos e as 12 horas oficiais, mas revisa a explicação conceitual para melhorar a aprendizagem autoinstrucional. Foram reforçados: distinção entre tarefa/processo/workflow/automação/agente; prompt como contrato; gargalos e métricas; contratos entre nós; diagnóstico de APIs; modelo mental de itens no n8n; quando não usar IA; autonomia em camadas para agentes; segurança em profundidade; e critérios de aceitação do Projeto Integrador. A página `revisao-conceitual.html` é complementar e não compõe as 12 horas oficiais.


## Novidades da v9 — visualização avançada

A v9 adiciona mapas visuais integrados aos módulos e laboratórios para contratos de prompt/API, caminhos de falha, retry/backoff, modularização, structured output x tool calling, ciclo de agente, contexto/estado/memória, segurança em camadas e observabilidade. A página `mapa-visual-avancado.html` é uma revisão opcional e não altera as 12 horas oficiais.
