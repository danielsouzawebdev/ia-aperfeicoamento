📚 Glossário

API

Interface que define como sistemas podem solicitar dados ou ações uns aos outros.

AS-IS

Descrição de como o processo funciona atualmente.

Agente inteligente

Sistema que usa um modelo e ferramentas para executar passos em direção a um objetivo, dentro de limites definidos.

Autenticação

Mecanismo usado para identificar e autorizar quem chama um serviço.

Conector

Integração pronta entre uma plataforma de automação e um serviço.

Endpoint

Endereço de uma operação/recurso de uma API.

Gatilho

Evento que inicia um workflow.

HTTP

Protocolo comum usado em comunicação com APIs web.

Human-in-the-loop

Ponto de revisão ou aprovação humana dentro de um fluxo automatizado.

JSON

Formato de dados estruturados em pares chave/valor, comum em APIs e automações.

Prompt engineering

Projeto sistemático de instruções, entradas, regras e formatos para obter saídas úteis e previsíveis.

Saída estruturada

Resposta em formato previsível, como JSON com campos definidos.

TO-BE

Descrição do processo desejado após a melhoria.

Webhook

URL que recebe uma requisição quando um evento ocorre em outro sistema.

Workflow

Sequência organizada de gatilhos, ações, decisões, dados e saídas.

n8n

Plataforma de automação de workflows usada como referência principal neste curso.

Produção e operação

Sub-workflow

Workflow chamado por outro workflow para encapsular uma responsabilidade.

Contrato de dados

Definição esperada de campos, tipos e regras entre componentes.

Observabilidade

Capacidade de compreender comportamento e saúde do sistema usando execuções, logs e métricas.

Correlation ID

Identificador usado para rastrear uma transação por etapas e sistemas.

Menor privilégio

Conceder somente permissões necessárias para executar uma tarefa.

Rollback

Estratégia para reverter ou desativar uma mudança com segurança.
