Regra do laboratório

Para o mini-projeto, a entrada só continua se nome, email e mensagem existirem. Isso exemplifica uma prática essencial: validar a entrada antes de chamar IA, API ou banco de dados.

Transferência para o n8n

No n8n real, configure um Webhook, envie um teste e observe a saída do nó. O objetivo não é decorar a tela: é reconhecer o JSON que passa a ser a entrada dos próximos nós.
